# [SLP][BUG-HVMB4G] Translate flash messages, popups and status labels on vi_VN storefront

<!-- External ticket: SLP-133. Scope: flash message (message manager + Magewire), popup/modal confirm (cookie consent, clear cart, vault, OSC survey), status label (empty-cart state, CSRF flash, review title) trên toàn storefront. -->

## Summary

Trên storefront vi_VN, các flash message (thành công/lỗi), popup/modal (confirm, cookie consent, OSC survey) và status message còn tiếng Anh: "Close message", "Allow Cookies", "Clear Shopping Cart", "Something went wrong. Please try again.", "The coupon code "%1" is not valid.", "One step checkout is turned off.", empty-cart "You have no items in your shopping cart."… Fix bằng cách bổ sung phrase vào theme dictionary — cùng pattern SLP-106→132, không sửa template `vendor/`.

## Mini Spec

### Goal

Toàn bộ chuỗi message/popup/status hiển thị tiếng Việt khi locale vi_VN; giữ English khi en_US. Đáp ứng BR-001 (mirror `vi_VN.csv` + `en_US.csv`).

### Expected Behavior

Mọi chuỗi render qua `__()` / `new Phrase` trong khu vực message-popup-status (renderer Hyva `messages.phtml`, template popup Hyva + Mageplaza storefront, controller frontend core + Mageplaza sinh flash, empty-state status) resolve qua theme dictionary `Secomm/launchpad/i18n/vi_VN.csv`.

### Constraints / Rules

- Không sửa template trong `vendor/` (chỉ fix qua theme dictionary).
- Không đổi placeholder `%1`/`%2`; giữ nguyên khoảng trắng đầu/cuối chuỗi khi là một phần key (`"The order wasn't placed. "`, `'The account sign-in was incorrect or your account is disabled temporarily. '` có **trailing space**); giữ double-space typo của core (`'Something went wrong  clearing the comparison list.'`); giữ HTML entity trong key JS (`'Gift Message Item &#40'`).
- BR-001: mirror cùng key vào `en_US.csv` (giá trị = bản English).
- Giữ format CSV: QUOTE_ALL + CRLF, append-only, không duplicate key.
- Chỉ thêm phrase frontend-visible thuộc message/popup/status.

## Steps to Reproduce

1. Storefront vi_VN → thêm product vào giỏ → flash hiển thị "Close message" (aria) và các flash coupon/cart bằng tiếng Anh.
2. Áp mã giảm giá sai → "The coupon code "X" is not valid."
3. Giỏ trống → "You have no items in your shopping cart." + "Click here to continue shopping."
4. POST với form_key sai → flash "Invalid Form Key. Please refresh the page."
5. Checkout success có survey → "Thank you for your feedback!", "You need to choose at least one answer."

## Expected Behavior

Các chuỗi trên hiển thị tiếng Việt trên locale vi_VN.

## Actual Behavior

Hiển thị English nguyên bản ( Steps to Reproduce).

## Root Cause

Kế thừa nguyên nhân BUG-HE2NGV/BUG-M33P7N: không có language pack vi_VN (0 file `vendor/magento/*/i18n/vi_VN.csv`, không có `app/i18n/*`; Hyva default theme chỉ ship `en_US.csv`) — theme dictionary là nguồn dịch duy nhất của storefront. Dictionary (696 dòng sau SLP-132) chưa phủ cụm message/popup/status: flash renderer (`messages.phtml` chỉ có "Close message"), popup templates (cookie/clear/vault/survey), và phrase sinh ra từ controller core (`module-checkout` Cart/CouponPost/Onepage, `module-contact`, `module-catalog` Compare…) + Mageplaza Osc/AbandonedCart controllers + framework CSRF validator.

## Fix

1. **Extraction** (script `extract-phrases.py`, evidence dir): grep `__()` từ nguồn message/popup/status — Hyva popup/consent/confirm templates (`Magento_Theme/messages.phtml`, `Magento_Cookie/notices.phtml`, `Magento_Checkout` php-cart `form/clear.phtml` + messages, `Magento_Vault`, `Hyva_Theme/elements/modal.phtml`, `Magento_OrderCancellationUi`, `Magento_Sales` order status/history/recent, `Magento_Catalog`/`GroupedProduct` stock-status, `Magento_Newsletter/subscribe`), child-theme overrides (ExtraFee, SocialLoginPro), Mageplaza storefront (Osc hyva templates + Controller, AbandonedCart frontend, DeliveryTime frontend, SocialLoginPro dashboard), message-dense frontend controllers core (checkout/customer/newsletter/review/contact/wishlist/catalog-compare/sales), JS `$t()` của Osc/OscPro/OscUltimate → 265 unique, còn thiếu **71** (skip by design: `'Test product'`).
2. **Append 71 phrase** (batch 1) vào `vi_VN.csv` + mirror `en_US.csv` — QUOTE_ALL + CRLF append-only, giữ placeholder/trailing-space/double-space/entity nguyên bản.
3. **Batch 2 (+2)**: empty-cart status (`noItems.phtml`) — "You have no items in your shopping cart." / "Click here to continue shopping." (phát hiện khi live-verify cart page).
4. **Batch 3 (+1)**: `Invalid Form Key. Please refresh the page.` — từ [CsrfValidator.php:103](vendor/magento/framework/App/Request/CsrfValidator.php#L103) (`new Phrase`), phát hiện live khi test flash pipeline.
5. `bin/magento cache:flush` + `setup:static-content:deploy -f vi_VN` (as www-data — LL-0003).
6. Verify 2 tầng theo LL-0004/0005: framework script → live fetch + decode entities.
7. **Batch 4 (+6, theo 8 screenshot QC của ticket)**: các flash add-to-cart/wishlist/compare dùng `addComplexSuccessMessage` — text render qua **message-renderer template riêng** với **key full-HTML có `<a href>`**, khác với plain key đã có sẵn trong dict: `You added %1 to your <a href="%2">shopping cart</a>.` ([addCartSuccessMessage.phtml:11](vendor/magento/module-checkout/view/frontend/templates/messages/addCartSuccessMessage.phtml#L11)), `Click <a href="%1">here</a> to continue shopping.`, `You added product %1 to the <a href="%2">comparison list</a>.`, + 3 key account-confirm lỗi (customerAlreadyExists/confirmAccount error+success).
