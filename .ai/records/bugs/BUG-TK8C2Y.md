# [SLP][BUG-TK8C2Y] Translate extra fee "(Excl. Tax)" suffix on cart totals

## Summary

Ở cart page (Hyvä), dòng Extra Fee hiển thị suffix `(Excl. Tax)` chưa dịch — "Extra_fee Cart - 20HKD(Excl. Tax)", "Bảo hiểm(Excl. Tax)". Root cause: suffix bị **hardcode trong Alpine `x-html`** của vendor template `Mageplaza_ExtraFee::hyva/cart/totals/extra-fee.phtml` (3 chỗ: dòng 43/63 `(Excl. Tax)`, dòng 52 `(Incl. Tax)`) — string JS thuần, không đi qua `__()` nên theme dictionary không bao giờ tác động (key `" (Excl. Tax)"` đã có sẵn trong theme CSV từ BUG-HVMB4G nhưng vô dụng ở layer này). Fix: child theme override template + inject suffix qua `__()` + `escapeHtml`; thêm key `" (Incl. Tax)"` mirror vi/en (BR-001).

**Scope extension 09-09 (user QC report trên demo, cùng ticket SLP-144 — mục (3) Out of Scope của BUG-HVMB4G):** message validation form Extra Fee ở cart hardcode `messageDiv.innerHTML = '<span>This is a required field</span>'` trong JS handler của `Mageplaza_ExtraFee::hyva/cart/extra-fee.phtml:429` (block `checkout.cart.extra.fee`, click `#checkout-link-button`). Fix: child theme override thêm template thứ 2 + inject `__('This is a required field.')` (Magento core phrase, key có sẵn cả 2 CSV từ trước — không cần thêm CSV).
