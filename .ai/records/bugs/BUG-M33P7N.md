## Summary

Trên storefront vi_VN, trang danh mục (category page) + product list hiển thị lẫn lộn tiếng Anh: toolbar "Sort By" / "Set Ascending Direction" / "Items 1-12 of 24", layered navigation "Shop By" / "Shopping Options" / "Clear All", facet Smile Elasticsuite ("Show more", slider aria, "No items in the current range."), product card "Add to Compare" / "Configure", empty state "We can't find products matching the selection.", minicart/menu/notices chrome. Fix bằng cách bổ sung phrase vào theme dictionary — cùng pattern SLP-106/118/121/128, không sửa template `vendor/`.

**Batch 2 (screenshot QC của ticket, 2026-08-28):** breadcrumb trang category còn "Home" — nguồn là core Block [Breadcrumbs.php:61-62](vendor/magento/module-catalog/Block/Breadcrumbs.php#L61) (`'label' => __('Home')` + `'title' => __('Go to Home Page')`), Block PHP nên đợt extraction 1 (templates-only) bị sót. Screenshot cũng xác nhận các mục đã fix batch 1 (`Shop By`, `Active filtering`, `Clear All`, `Category`, `Position`) và các mục store-data thuộc Out of Scope.

## Mini Spec

### Goal

Toàn bộ chuỗi UI của khu vực product list / category page hiển thị tiếng Việt khi locale vi_VN; giữ English khi en_US. Đáp ứng BR-001 (mirror `vi_VN.csv` + `en_US.csv`).

### Expected Behavior

Mọi chuỗi render qua `__()` trong khu vực category/product-list (templates Hyva fallback + core PHP + Smile Elasticsuite frontend + layout labels `translate="true"`) resolve qua theme dictionary `Secomm/launchpad/i18n/vi_VN.csv`.

### Constraints / Rules

- Không sửa template trong `vendor/` (chỉ fix qua theme dictionary).
- Không đổi placeholder `%1`/`%2`/`%0`/`%s`/`<%- count %>`; giữ khoảng trắng đầu/cuối chuỗi khi là một phần key (`' filter'`, `'Buy %1 for %2 each and '`); giữ nguyên HTML trong chuỗi có `<b>`.
- BR-001: mirror cùng key vào `en_US.csv` (giá trị = bản English).
- Giữ format CSV: QUOTE_ALL + CRLF, không duplicate key mới.
- Chỉ thêm phrase **frontend-visible**.

### Out of Scope

- **Facet/sort attribute labels** ("Category"/"Price"/"Color"/"Size"/"Shipping Group" trong filter và sort-by dropdown): attribute frontend labels là **store data (DB)** — render không qua `__()`. Action cho client/QC: đặt "Default Store View label" trong Admin (Stores → Attributes → Product). Chỉ "Position" là dictionary-dịch được (`[Config.php:482](vendor/magento/module-catalog/Model/Config.php#L482)`). Screenshot ticket cho thấy "Giá"/"Tên sản phẩm" đã có vi store label (đặt trước đó), "Color"/"Shipping Group" chưa.
- **Attribute option values** (vd "Sage" của Color): store data — Admin (Stores → Attributes → Product → Color → Manage Labels nếu cần).
- **Category name/description, H1/SEO title per store view** (vd "Accessories", "Sage Accessories (Custom SEO H1)"), **product descriptions** English + **mojibake `bouclÃ©`** (UTF-8 double-encoded trong DB — nhập lại nội dung): đều là catalog content per store view, không thuộc dictionary.
- **PDP-only strings** (gallery, quantity, custom options, PDP price "As low as"): thuộc ticket translate product page riêng (nếu có).
- **Advanced search page** (Magento_CatalogSearch advanced/*): trang riêng, không thuộc "category page".
- Email templates (cơ chế `{{trans}}`, xem memory).

## Actual Behavior

Hiển thị English nguyên bản (xem Steps to Reproduce).

## Root Cause

Kế thừa nguyên nhân BUG-HE2NGV/BUG-8K1TBB: core không ship language pack vi_VN, theme không override template catalog (fallback Hyva default theme + Smile Elasticsuite compat), theme dictionary (584 dòng) chỉ chứa chuỗi các khu vực đã fix trước (blog/review/checkout-email/account/…) — chưa phủ cụm catalog category/product-list. Layered navigation còn chạy qua **Smile Elasticsuite** ( facets + autocomplete) nên nguồn phrase trải thêm module này.

**Phát hiện ngoài ticket (cần update project-context):** AGENTS.md §6 ghi "no ElasticSuite (core Magento search only)" đã **stale** — Smile_Elasticsuite* + Hyva_SmileElasticsuite enabled trong `app/etc/config.php`, theme đã có override [hyva_catalog_category_view.xml](app/design/frontend/Secomm/launchpad/Hyva_SmileElasticsuite/layout/hyva_catalog_category_view.xml).

## Fix

1. **Extraction** (script `extract-phrases.py`, evidence dir): grep `__()` (unescaped `\'`/`\"`, giữ nguyên khoảng trắng đầu/cuối) từ Hyva default theme in-scope trees (Catalog navigation/category/list/compare/widget-viewed/slider/price-tier, LayeredNavigation, CatalogWidget, Theme html pager/header/cart/notices/collapsible/footer) + Hyva_SmileElasticsuite + Smile_ElasticsuiteCatalog/Swatches frontend templates + layout `translate="true"` (autocomplete titles, compare page title) + core PHP (`Magento\Catalog\Model\Config` 'Position', Smile Slider block + Price/Decimal filter models — range labels '%1 and above', '%1 - %2') → 135 unique phrase, diff dictionary còn thiếu **105**.
2. Loại trước đó: bare placeholders (`%1`…), phrase đã có trong dict (30 — gồm `%1 Item(s)`, `Page`, `Previous/Next Page`, `You're currently reading page`, `Add to Cart`…).
3. **Append 105 phrase** vào `vi_VN.csv` + mirror `en_US.csv` (105 dòng, giá trị = English) — QUOTE_ALL + CRLF giữ nguyên.
4. `bin/magento cache:flush` (as www-data — BUG-SDZPCD/LL-0003).
5. Verify 2 tầng theo LL-0004: framework-level script (boot Magento, area frontend, theme Secomm/launchpad, locale vi_VN, assert phrase) → live fetch trang category (session fresh) → grep chuỗi vi + English leftover.

6. **Batch 2 (+2 phrase, theo screenshot QC ticket)**: `Home` → "Trang chủ" + `Go to Home Page` → "Về trang chủ" (cả hai từ core Block [Breadcrumbs.php:61-62](vendor/magento/module-catalog/Block/Breadcrumbs.php#L61), thêm vào PHP_SOURCES của extract script). Cập nhật verify list → 107 phrase.

Files changed: `app/design/frontend/Secomm/launchpad/i18n/vi_VN.csv` (+107), `en_US.csv` (+107). Dictionary: 584 → 691 dòng mỗi file.

**Lưu ý dictionary area-wide:** key generic mới (`Position`, `Details`, `Compare`, `Contact`, `OK`, `item(s)`…) dịch toàn frontend area — mọi module dùng đúng phrase đó hiển thị đồng nhất (mong muốn).
