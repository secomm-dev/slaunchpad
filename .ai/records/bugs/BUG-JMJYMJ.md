# [SLP][BUG-JMJYMJ] Translate search result page strings on vi_VN storefront

<!-- External ticket: SLP-206. Generated by Claude Code per bug-record-template (Mode C). -->

## Summary

Trên trang kết quả tìm kiếm `/catalogsearch/result/` storefront vi_VN, 5 chuỗi UI hiển thị English: breadcrumb + H1 + page title ("Search results for: 'test'"), notice spellcheck ("No exact results found for: 'test'. The displayed items are the closest matches."), tiêu đề block gợi ý ("Did you mean"), option sort ("Relevance" — các option khác đã dịch) và notice không kết quả ("Your search returned no results.").

## Mini Spec

### Goal

Toàn bộ chuỗi UI của trang kết quả tìm kiếm hiển thị tiếng Việt trên locale vi_VN, đáp ứng BR-001 (bilingual vi_VN/en_US; chuỗi phải có ở cả `vi_VN.csv` + `en_US.csv`).

### Expected Behavior

Các phrase trên (dịch qua theme dictionary) render tiếng Việt khi locale vi_VN ở cả 3 trạng thái trang: kết quả spellcheck, kết quả thường, không có kết quả; sort dropdown hiển thị option đã dịch. Locale en_US giữ nguyên English.

### Constraints / Rules

- Không sửa template/block trong `vendor/` (Magento core, Smile ElasticSuite, Hyvä) — chỉ fix qua theme dictionary (pattern BUG-8K1TBB / BUG-KFJ49A).
- Không đổi placeholder `%1` và markup `<b>...</b>` trong phrase spellcheck (render qua `@noEscape` — sai sẽ vỡ output).
- BR-001: mirror cùng dòng key vào `en_US.csv`, giá trị = English.
- Giữ nguyên định dạng CSV hiện có (`"source","translation"`, không header, LF) — append cuối file, không duplicate key.
- Phrase #3 (`Did you mean`) và #6 (`Related search terms`) là XML arg `translatable="true"` của `Magento\AdvancedSearch\Block\Suggestions` / `Recommendations` — vẫn resolve qua theme dictionary.

### Out of Scope

- Gợi ý tìm kiếm ("teak", "that", search terms) — store data, không dịch qua CSV.
- Thu hồi doc drift của AGENTS.md §2/§6 ("no ElasticSuite" — stale, thực tế Smile_Elasticsuite* + Hyva_SmileElasticsuite enabled, search chạy ElasticSuite/OpenSearch) — flag TL để update project-context theo §14, không thuộc change set.
- Bản dịch cho các trang/module khác ngoài trang kết quả tìm kiếm.

### Acceptance Criteria

- AC-001: Locale vi_VN, trang `/catalogsearch/result/?q=test` (spellcheck match): H1 + breadcrumb "Kết quả tìm kiếm cho: 'test'"; notice "Không tìm thấy kết quả chính xác cho: <b>'test'</b>. …" giữ markup + placeholder; block gợi ý "Ý của bạn là".
- AC-002: Sort dropdown hiển thị "Độ phù hợp" (các option còn lại giữ nguyên bản dịch có sẵn).
- AC-003: Locale vi_VN, query không có kết quả: notice "Tìm kiếm của bạn không trả về kết quả nào."
- AC-004: `en_US.csv` có đủ dòng key mirror (giá trị English) — BR-001; locale en_US hiển thị English như trước.
- AC-005: Dictionary framework-level resolve đủ 6/6 phrase (`Related search terms` → "Từ khoá tìm kiếm liên quan") trong area frontend, theme `Secomm/launchpad`, locale vi_VN.

## Steps to Reproduce

1. Mở `/catalogsearch/result/?q=test` trên storefront vi_VN.
2. Quan sát: breadcrumb + H1 English; notice spellcheck English; block gợi ý "Did you mean" English; sort dropdown "Relevance" English.
3. Mở `/catalogsearch/result/?q=%23%25%5E%26%26**` (không có kết quả): notice "Your search returned no results." English.

## Expected Behavior

Các chuỗi trên hiển thị tiếng Việt trên locale vi_VN.

## Actual Behavior

Hiển thị English nguyên bản (xem Steps to Reproduce).

## Root Cause

Giống BUG-8K1TBB: Magento core không ship language pack vi_VN; theme `Secomm/launchpad` không override template `Magento_CatalogSearch` (fallback Hyvä + module templates); theme dictionary chưa có phrase nào của trang search → `__()` fallback English. Trang search chạy Smile ElasticSuite (`ResultPlugin` thêm notice spellcheck; sort "Relevance" do `Magento\CatalogSearch\Block\Result` inject).

## Approach

Specification: Embedded Mini-Spec — BUG-JMJYMJ (SLP-206)

1. Append 6 phrase pairs vào `app/design/frontend/Secomm/launchpad/i18n/vi_VN.csv` + mirror `en_US.csv` (key = English):
   - `Search results for: '%1'` → `Kết quả tìm kiếm cho: '%1'`
   - `No exact results found for: <b>'%1'</b>. The displayed items are the closest matches.` → `Không tìm thấy kết quả chính xác cho: <b>'%1'</b>. Các sản phẩm hiển thị là những kết quả phù hợp nhất.`
   - `Did you mean` → `Ý của bạn là`
   - `Relevance` → `Độ phù hợp`
   - `Your search returned no results.` → `Tìm kiếm của bạn không trả về kết quả nào.`
   - `Related search terms` → `Từ khoá tìm kiếm liên quan` (+1 key ngoài screenshot — cùng block family `Magento_AdvancedSearch`, chốt trong phân tích SLP-206)
2. `bin/magento cache:flush` (chạy as `secomm`).
3. Verify: script dictionary framework-level (pattern `verify-i18n.php` BUG-8K1TBB) + curl 3 trạng thái trang (vi/en) + scope check git diff.
