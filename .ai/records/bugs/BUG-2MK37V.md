## Summary

Trên checkout Mageplaza OSC, section discount code (`.payment-option.opc-payment-additional.discount-code` — render Knockout template `Mageplaza_Osc/view/frontend/web/template/container/payment/discount.html`, nằm dưới khối Payment Methods) bị lệch hàng: nút **Apply Discount** thấp hơn input đúng **+12px** (baseline live đo được `dTop = dBottom = 12`). Checkout chạy **Magento/luma scope** (LL-0011) — CSS theme `Secomm/launchpad` không load; section nhận style từ Luma `styles-m.css` + vendor `Mageplaza_Osc::css/style.css` + `Mageplaza_Core/css/grid-mageplaza.css`. Cơ chế lệch (baseline): `.payment-option-inner` là `flex space-between` nhưng `align-items: normal` (stretch); toolbar Luma `padding-top: 12px`; `.control` có `margin-bottom: 10px` + chứa label chiếm ~14px → inner cao 60px, toolbar stretch theo, button (36px) nằm lệch đáy so với input (36px ở đỉnh). Thêm nhiễu: vendor `#discount-form input[type="text"] { width: 98% !important }` (input 250px trong control 255px), vendor `.osc-payment-after-methods .opc-payment-additional .field .control { float:left; width:100% }` (placement-dependent).

## Steps to Reproduce

1. Storefront → cart có sản phẩm → `/onestepcheckout/`.
2. Khu vực Payment Methods → section "Enter discount code" dưới cùng.
3. Nút "Apply Discount" lệch thấp so với input, có line kẻ phía trên nút.

## Expected Behavior

Input và nút thẳng hàng, cùng chiều cao, không có phần tử thừa.

## Actual Behavior

Nút trôi thấp (margin-top + padding-top + border-top từ `.actions-toolbar` của theme; input `width: 98% !important` của vendor gây gap phải).

## Root Cause

Checkout OSC chạy Magento/luma scope (LL-0011) và section discount không được style chủ đích ở scope này: Luma style `.actions-toolbar` với `padding-top: 12px` + template vendor có inline `margin-top: 0` (chỉ triệt tiêu margin, không triệt tiêu padding); `.payment-option-inner` (vendor `style.css`) là `display:flex; justify-content:space-between` nhưng **không có `align-items`** → stretch; `.control` (label bên trong chiếm ~14px chiều cao + margin) làm hàng cao bất đối xứng → nút 36px lệch đáy +12px so với input 36px. Vendor `#discount-form input[type="text"] { width: 98% !important }` cộng thêm gap phải lẻ của input.

## Fix

1. ✅ Baseline live DOM (Playwright, pattern BUG-NY0M3S): misalign đo được **+12px đều top/bottom** (toolbar Luma `padding-top:12px` + control `margin-bottom:10px` làm inner cao 60px trong khi input/button 36px); input `width:98% !important` (vendor); button Luma `rgb(1,0,127)`; inner `align-items: normal` (stretch).
2. File mới `app/code/Launchpad/Osc/view/frontend/web/css/osc-discount-code.css`: scoped `.opc-payment-additional.discount-code` — toolbar reset (margin/padding/border 0, `align-items:center`), `.control.input-field` `flex:1 1 auto; min-width:0; margin-bottom:0` (+ label layout tuỳ baseline), input `width:100% !important` (specificity `(1,2,1)` > vendor `(1,1,1)`).
3. Thêm `<css src="Launchpad_Osc::css/osc-discount-code.css"/>` vào layout có sẵn `app/code/Launchpad/Osc/view/frontend/layout/onestepcheckout_index_index.xml` (head).
4. `cache:flush` as secomm (layout cache; developer mode materialize static on-demand).
