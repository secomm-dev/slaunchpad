## Summary

Follow-up BUG-2MK37V (SLP-199): sau fix align section discount code, UI **vẫn lệch khi validation message hiển thị** — submit form với input rỗng → mage/validation chèn message "Đây là một trường bắt buộc." → nút **Apply Discount tụt xuống +12.1px** so với input (baseline live đo được, cả 1280 và 375). State không-error vẫn 0/0.

## Mini Spec

### Goal

Section discount code: nút **thẳng hàng với input ở mọi state**, kể cả khi `.mage-error` hiển thị. Message vẫn render dưới input, đọc được, không đè nội dung khác. Display-only, CSS-only.

### Root Cause

- mage/validation (`errorPlacement`, mage/validation.js:1876–1907): input text thường → error div chèn **ngay sau input, bên trong `.control`** (input cũng bị add class `mage-error` — line 1614, chỉ là red border).
- Khi message xuất hiện, `.control` cao 36 → **60.1px** (input 36px + message line 17.1px + 7px margin).
- CSS BUG-2MK37V đặt `.payment-option-inner { align-items: center }` → toolbar 36px bị **center theo row 60.1px** → nút tụt (60.1 − 36)/2 ≈ **+12.1px**.
- Vì sao BUG-2MK37V verify PASS mà vẫn lộ: state không-error mọi box 36px nên `center` ≡ `flex-start`; state validation-error không nằm trong AC-001..005 cũ.

## Actual Behavior
