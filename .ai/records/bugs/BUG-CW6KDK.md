## Summary

4 issue từ screenshot QC trên store vi_VN:

1. `/customer/account/login/` POST sai credentials → message EN. Nguồn:
   `Magento\Customer\Controller\Account\LoginPost.php:213` — `__()` wrap chuỗi full
   `"The account sign-in was incorrect or your account is disabled temporarily. Please wait and try again later."`.
   Theme CSV hiện có 2 key **bị cắt cụt** (vi_VN dòng 328 + 741 — thiếu suffix "Please wait…")
   → không khớp full phrase → fallback EN.
2. `/customer/account/edit/` tooltip assistance còn EN. Nguồn: config value
   `shopping_assistance_checkbox_tooltip` (`Magento_LoginAsCustomerAssistance/etc/config.xml:14`),
   render qua Hyva vendor template `shopping-assistance.phtml` đã wrap `__(config value)` →
   CSV key fix được. Label đã dịch sẵn, chỉ thiếu tooltip (chuỗi chứa `"see what you see"` →
   CSV escape `""`).
3. Trang share wishlist (`wishlist/share/index`): submit button "Chia sẻ danh sách yêu thích"
   render như text thường — template `Magento_Wishlist::sharing.phtml` (Hyva vendor, child theme
   chưa có override) dùng class `action submit primary` mà theme không style. Yêu cầu QC:
   style dạng nút để phân biệt thao tác (button) vs text ("Quay lại" là link).
4. Bubble native HTML5 "Please fill out this field." (browser-language, KHÔNG phải site string —
   không dịch được qua CSV) trên textarea `emails` có attr `required`.

## Mini Spec

### Goal

- Store vi_VN: (1) login error + (2) assistance tooltip render VI; (4) empty-field validation
  trên form share wishlist hiển thị message VI thay bubble browser.
- Store en_US: identity sạch (không đổi hiển thị).
- (3) Submit "Share Wish List" style dạng nút primary của theme; "Back" giữ dạng link.
- Không thay đổi logic auth/flow; không đụng vendor `magento/*` + `hyva-themes/*`.

### Acceptance Criteria

  [[magento-cli-phrase-verify]]) — PASS.

- AC-003: override `sharing.phtml` load đúng (template fallback child theme), submit button có

  giữ nguyên hành vi — PASS (diff verbatim + minimal).

## Fix

- `app/design/frontend/Secomm/launchpad/i18n/vi_VN.csv` + `en_US.csv`: +2 key (login error full
  phrase; tooltip assistance). Mirror identity BR-001.
- Override mới `app/design/frontend/Secomm/launchpad/Magento_Wishlist/templates/sharing.phtml`
  (copy verbatim vendor Hyva + 3 diff: (a) bỏ attr `required` trên textarea emails, (b) mở rộng
  `validateForm()` check empty → `setCustomValidity(__('This is a required field.'))` trước check
  format, (c) submit button thêm class `btn btn-primary` — button component sẵn có của theme
  (login form, wishlist sidebar dùng cùng class; `btn-primary` đã compile trong styles.css).
- Cơ chế (4): bỏ `required` để bubble browser không fire; empty → setCustomValidity(customError)
  → constraint validation của browser tự chặn submit + hiển thị message VI từ dictionary.
  `@blur`/`@input.debounce` giữ nguyên → validity tự clear khi user gõ.
- Cache: `cache:clean translate` (hoặc flush) as secomm sau khi sửa CSV.
