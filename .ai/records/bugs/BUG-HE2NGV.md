Fix bằng cách bổ sung **292 phrase** vào theme dictionary — cùng pattern SLP-106/118/121, không sửa template `vendor/`.

**Batch 3 (screenshot thứ 2 — order view header/tabs/status, 2026-08-27):** còn thiếu "Order Date:", tabs Order/Invoices/Shipments, "Delivery On:" (Mageplaza DeliveryTime), status "Complete", sidebar "Dashboard". ## Mini Spec

### Goal

Toàn bộ chuỗi UI của khu vực My Account hiển thị tiếng Việt khi locale vi_VN; giữ English khi en_US. Đáp ứng BR-001 (mirror `vi_VN.csv` + `en_US.csv`).

### Expected Behavior

Mọi chuỗi render qua `__()` trong khu vực account (templates Hyva fallback + core controllers + module bên thứ 3 có account section) resolve qua theme dictionary `Secomm/launchpad/i18n/vi_VN.csv`.

### Constraints / Rules

- Không sửa template trong `vendor/` (chỉ fix qua theme dictionary).
- Không đổi placeholder `%1`/`%2`; giữ nguyên HTML trong chuỗi có `<a href>`/`<strong>`.
- BR-001: mirror cùng key vào `en_US.csv` (giá trị = bản English).
- Giữ format CSV: QUOTE_ALL + CRLF, không duplicate key mới.
- Chỉ thêm phrase **frontend-visible**; bỏ phrase admin-only (theme dictionary không load ở admin area).

### Out of Scope

- **"Colorrr" / "Colorrrr"** (4 vị trí trên order view): tên ExtraFee rule/option do admin cấu hình trong DB — store data, Hyva render `$total->getLabel()` thô (không qua `__()`) nên dictionary không áp dụng. **Action cho client/QC:** đổi tên trong Admin (Mageplaza ExtraFee → Manage Rules) — hiện là tên test.
- Order view các chuỗi cần dữ liệu thật khác (invoice/shipment print PDF) — phrases đã có trong dictionary, browser QC thuộc QC team.
- Product alert email body (email i18n = cơ chế `{{trans}}`, xem memory).
- **Order status label per-store**: dictionary dịch được default labels qua `__()` fallback ([Status.php:157](vendor/magento/module-sales/Model/Order/Status.php#L157)) — đã thêm 8 status phổ biến; nếu admin đặt "Store View Label" riêng thì label đó thắng dictionary (một hành vi đúng của Magento).
- **Shipping/Payment method title** ("Flat Rate - Fixed", "Check / Money order"): store config values render thô — đổi title trong Admin per store view (Stores → Configuration → Sales → Shipping/Payment Methods), không thuộc dictionary.

## Root Cause

Khu vực account trải rộng nhiều module (Magento_Customer/Sales/Wishlist/Newsletter/ProductAlert/Vault + OrderCancellationUi + Mageplaza_SocialLoginPro) nên các đợt fix trước (mỗi đợt theo page/module đơn lẻ) chưa phủ hết.
