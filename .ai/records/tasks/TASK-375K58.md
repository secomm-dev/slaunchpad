# [SLP][TASK-375K58] [Homepage] Config auto slide (marquee vô hạn) cho Category slider (SLP-267)

<!-- External ticket: SLP-267 (extension của TASK-HARDAR — section Category slider trên home). Mode C — embedded Mini-Spec + Approach. -->

## Summary

Thêm config **auto slide** vào widget `categories_a` (homepage Category slider của TASK-HARDAR): **bật** → slider chạy **marquee liên tục vô hạn** (infinity horizontal scroll); **tắt** → giữ nguyên behavior hiện tại (kéo chuột + dots). Mặc định **Off**, không đổi payload homepage `home` (admin tự bật qua form widget).

PM confirm (2026-10-05): behavior = **marquee chạy liên tục** (không phải autoplay step); rollout = **config-only mặc định Off**.

## Mini Spec

### Goal
Admin bật/tắt auto slide cho từng instance widget `categories_a` + chỉnh tốc độ; storefront render marquee vô hạn mượt khi bật.

### Expected Behavior
1. Form widget (admin) hiện 2 field mới: `Enable Auto Slide (Marquee)` (yesno, default `No`) + `Marquee Speed: Seconds per Loop` (integer 5–120, default 30).
2. `auto_slide = Yes`: tile trượt ngang liên tục, đều, **không dừng/không cần thao tác**; hết cuối vòng **quay vòng liền mạch** (không jump nhìn thấy được); chạy mọi breakpoint.
3. Hover chuột / focus vào section → **pause**; rời đi → chạy tiếp.
4. `auto_slide = No` (mặc định, cả payload cũ không có field): behavior **nguyên trạng** TASK-HARDAR (kéo chuột, dots mobile/tablet, desktop 6 tile/khung).
5. `prefers-reduced-motion: reduce` → không chạy marquee, fallback slider thường.
6. Không phát sinh page horizontal-scroll; không pageerror; link tile (kể cả clone) vẫn click được.

### Constraints / Rules
- Config-only: KHÔNG đổi payload/content DB của page `home`; payload cũ thiếu field mới vẫn validate PASS (SchemaValidator lấy `default` cho field thiếu — SchemaValidator.php:47), `schema_version` giữ 1.
- Marquee mode **không** init `SnapSlider`/`enableMouseDrag` (tránh xung đột snap/dots/inert); reduced-motion thì vẫn init slider thường.
- Clone tile set bằng JS (`aria-hidden="true"` + `tabindex="-1"` trên anchor) — đủ bộ để `scrollWidth ≥ cycle + clientWidth`.
- Tailwind v4 CSS-first; không tạo `tailwind.config.js`; CSS thuần trong `homepage.css` (đã LF).
- Không sửa template gốc `Secomm_UiWidget` (chỉ definition + test — module Secomm-owned như ValidateWidgetParameters của TASK-HARDAR r3).

### Out of Scope
- Nút pause hiển thị (a11y strict — pause-on-hover/focus + reduced-motion là đủ; nút pause là follow-up nếu PM yêu cầu).
- Bật auto_slide cho homepage hiện tại (admin tự bật).
- Marquee cho slider khác (flash sale, promo, card gallery).

### Acceptance Criteria
- [ ] AC1: Field mới validate đúng — unit test PASS (`auto_slide` default false, `marquee_duration` default 30 min 5 max 120); payload cũ (không field) vẫn validate PASS.
- [ ] AC2: Mặc định (Off) — storefront 375/768/1440 behavior nguyên trạng: kéo chuột snap về tile, dots mobile/tablet, 0 pageerror (regression TASK-HARDAR).
- [ ] AC3: Bật marquee (probe inject `data-lp-marquee`): `scrollLeft` tăng liên tục đều; qua mốc cycle wrap về không jump nhìn thấy (vị trí tile liền mạch); đủ clone `aria-hidden`; hover → pause, rời → chạy tiếp.
- [ ] AC4: Marquee ON — 375/768/1440: không page h-scroll, không pageerror; click tile (base + clone) vẫn mở đúng category URL.
- [ ] AC5: `prefers-reduced-motion: reduce` + marquee config ON → slider thường (kéo/dots) hoạt động, không marquee.
- [ ] AC6: Admin round-trip (manual — cần cred admin): sửa field trong form widget → Save → storefront nhận config (trap LL-0039 payload=).

## Approach

1. `CategoriesADefinition`: 2 field optional có default sau `mobile_slider` (schema v1 giữ nguyên) + unit test.
2. Template theme `a.phtml`: `$autoSlide` → section thêm class `lp-cat-slider--marquee` + `data-lp-marquee="<duration>"`; marquee ON ghi đè `--static` (rail mọi breakpoint).
3. `sliders-init.phtml`: `enableCatMarquee(root, track)` — đo cycle (base tiles + column-gap), clone đủ bộ, rAF tăng `scrollLeft` (`speed = cycle/duration` px/s), wrap `scrollLeft -= cycle` khi `≥ cycle`, pause hover/focus, clamp dt, ResizeObserver đo lại cycle + clone thêm; el có marquee → skip SnapSlider/enableMouseDrag (trừ reduced-motion).
4. `homepage.css`: marquee mode tắt scroll-snap + Ẩn overflow (`overflow-x: hidden`) + cursor default; track giữ scroll container + bleed phải (clip đúng vùng content→viewport edge).
5. Build Tailwind + bump `deployed_version.txt` + `cache:flush`; verify Playwright AC2–AC5 (ON qua route-inject attribute, OFF regression); evidence `.ai/evidence/TASK-375K58/`; CHANGELOG 2 module.

**Thiết kế marquee — scrollLeft rAF thay CSS transform:** track hiện là scroll container với bleed `margin-inline-end: calc(50% - 50vw)` — scroll container tự clip đúng vùng content-box → mép phải viewport; CSS transform trên track/con sẽ cần restructure DOM hoặc clip-path hack, và mất bleed. `scrollLeft` write mỗi frame là pattern drag hiện có (rẻ, 1 rail).

- `sliders-init.phtml`: module `enableCatMarquee(root, track)` — đo `cycle` từ base tiles + `columnGap`, clone nguyên bộ đến khi `scrollWidth ≥ cycle + clientWidth` (clone `aria-hidden="true"` + `tabindex="-1"`), rAF tăng `scrollLeft` tốc độ `cycle/duration` px/s, wrap `scrollLeft -= cycle` khi `≥ cycle`; pause `pointerenter`/`focusin`, resume `pointerleave`/`focusout`; dt clamp 0.05s (tab ẩn); ResizeObserver đo lại cycle + clone thêm + `scrollLeft %= cycle`. Init loop: el có `closest('[data-lp-marquee]')` → skip SnapSlider + enableMouseDrag, trừ khi `prefers-reduced-motion: reduce` (fallback slider thường).

- Build Tailwind (`.lp-cat-slider--marquee` vào styles.css) + bump `deployed_version.txt` → `1790932977` + `cache:flush`.
