# [SLP][FEAT-YA2C0W][TASK-9394A9] Phase C — Scheme registry + historical unit reference layer

## Summary

Bảng `secomm_vietnam_address_scheme` (registry, status CURRENT/HISTORICAL/FUTURE) + `secomm_vietnam_address_unit` (portable, code-identified, tích lũy mọi scheme từng import) + read API `VnAddressUnitProviderInterface`. Importer hook ghi snapshot + registry sync sau mỗi import thành công.

## Mini Spec

### Goal
Sau khi swap runtime sang scheme mới, đơn vị hành chính của scheme cũ vẫn resolvable bằng code — phục vụ mapping/resolution (Phase D) và carrier compat (Phase E).

### Expected Behavior
1. `etc/db_schema.xml` (đầu tiên của module) + whitelist: registry (scheme_code PK, label, profile_code, level_count, status, effective_from/to NULL, index status) + unit (entity_id PK, scheme_code, code, parent_code NULL, region_code, level 1|2|3, name_vi, name_en; UNIQUE(scheme_code, code); index (scheme_code, parent_code); KHÔNG FK runtime). Region rows lưu level 1.
2. `Model/Scheme/VnSchemeRegistry.php`: get/getCurrent/getAll (parameterized).
3. `Model/Import/SchemeRegistryUpdater.php`: imported → CURRENT; CURRENT cũ → HISTORICAL; FUTURE untouched; upsert từ VnSchemes catalog.
4. `Model/Import/UnitSnapshotWriter.php`: upsert ON DUPLICATE (names/parent/region/level update; code immutable); batch ~500; gọi MỖI import (tích lũy; swap không đụng).
5. `Api/VnAddressUnitProviderInterface` + `Model/VnAddressUnitProvider` + `Api/Data/VnAddressUnitInterface` DTO: getUnit(scheme, code), getChildren(scheme, parentCode), countByScheme.
6. Importer: sau stale cleanup → unitSnapshot → registryUpdater → membership → config → cache. Report thêm `unitsSnapshoted`.

### Constraints / Rules
- KHÔNG FK tới runtime tables (portable cross-environment/cross-swap); KHÔNG city_id/region_id DB-sinh trong bảng.
- Status là label, không phải identity; không rename scheme cũ khi có scheme mới.
- Declarative schema + whitelist generate; bảng additive.

### Out of Scope
Mapping/resolution (TASK-J9AVGK); admin UI cho registry (source model Phase B đã đọc registry).

### Acceptance Criteria
- AC-001: import VN_ADMIN_2025 → unit 3.355 rows (34 region level 1 + 3.321 level 2); registry 1 row CURRENT.
- AC-002: swap PRE_2025 → unit tích lũy ~14.917; registry 2 rows (2025 HISTORICAL, PRE_2025 CURRENT); swap ngược đổi lại đúng.
- AC-003: re-import cùng scheme → upsert names, không nhân bản (UNIQUE giữ); codes không đổi.
- AC-004: provider getUnit/getChildren trả đúng per scheme; countByScheme đúng.
