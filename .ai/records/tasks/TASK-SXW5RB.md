## Summary

`Snowdog_Menu` khi enabled remove 2 block nav native của Hyvä (`topmenu_mobile`, `topmenu_desktop`) trong `view/frontend/layout/default_hyva.xml` và thay bằng `Snowdog\Menu\Block\Menu` trỏ identifier admin (`hyva-topmenu-desktop/mobile/footer`). Khi chưa có menu data → render rỗng im lặng → header mất nav. Trạng thái hiện tại: module bị **disable bằng config.php** (diff uncommitted của session khác, 2026-09-15 — thấy trong TASK-Z3DAH5 §Traps) để nav native chạy lại, nhưng mất luôn admin menu builder.

Task này tạo **runtime config** `snowdog_navigation/general/enabled` (default No) trong module mới `Launchpad_SnowdogMenu`: tắt = nav native Hyvä render đầy đủ + Snowdog blocks output rỗng; bật = Snowdog nav như chủ đích SLP-29. Module **không bao giờ cần disable** → admin menu builder luôn khả dụng. Zero sửa code Snowdog/vendor.

## Findings cơ chế layout (đã verify vendor code trước khi thiết kế)

1. **`remove="false"` = un-remove first-class**: `Magento\Framework\View\Layout\Reader\Block.php:229-235` — attribute `remove` falsy-truthy-string (`"false"`) → `unsetElementFromListToRemove()` gỡ khỏi removal list. Theme file merge SAU module file → restore thắng. Pattern đã dùng trong chính theme file này cho `footer-static-links` (commit `636a5df8`).
2. **`ifconfig` KHÔNG hoạt động trên `<referenceBlock>`**: `parseConditions()` chỉ được gọi trong `scheduleBlock()` (Reader/Block.php:165), không có trong `scheduleReference()`. → không thể ifconfig 1 lệnh remove/un-remove.
3. **Redeclare block trùng tên = DESTRUCTIVE**: `ScheduledStructure/Helper.php::_overrideElementWorkaround` destroy element cũ + toàn bộ children rồi thay bằng node mới → bare-redeclare chỉ để thêm ifconfig sẽ mất class/arguments của module.
4. **Conditions đánh giá SAU removals** (`GeneratorPool::buildStructure:137-148`) — thứ tự an toàn cho thiết kế restore + plugin gate.
5. `addUpdate()` trong observer `layout_load_before` chạy TRƯỚC file XML (`Builder.php:79` dispatch trước `Update::load()`) → counter-XML bị đè → loại phương án observer.
6. `default_hyva` handle dùng chung với `Hyva_ThemeModule` (head/js, alpine plugins) → loại phương án removeHandle.
