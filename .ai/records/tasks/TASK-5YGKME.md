`STATUS_SELECTED` với candidate đầu theo `sort($codes, SORT_STRING)` (deterministic).

- 0 curated primary → SELECTED top-sorted (mới).
- 1 curated primary → SELECTED primary (curated thắng — không đổi).

- <2 candidates → NOT_APPLICABLE (không đổi).
- Handoff service: code path không đổi (SELECTED → resolved; else fail-closed defensively).
