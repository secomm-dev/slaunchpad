## Mini Spec

### Goal

Mini-cart drawer trên mọi trang Hyvä scope (catalog/PDP/cart) cho customer: chỉnh qty inline, remove item, xem subtotal đồng bộ backend, apply/remove coupon, thấy promo message — không reload page.

### Expected Behavior

- **Qty stepper** (− / + kèm input số): debounce ~500ms rồi POST `checkout/sidebar/updateItemQty` (form: `item_id` + `item_qty`, reuse `hyvaAjaxFormMinicart` có sẵn); min=1 client clamp (muốn bỏ → remove); vượt max/salable qty → server validate, per-item error message qua cơ chế `minicart-error-message` hiện có; đang POST → loading overlay (child block `loading` hiện có); subtotal tự refresh qua sections.
- **Remove**: giữ nguyên behavior native (AJAX, không reload).
- **Coupon**: input + Apply; đã applied → hiển thị mã + Cancel. POST `quickcart/coupon/post` (module `Launchpad_QuickCart`, AJAX controller delegate `CouponManagement` trên session quote — server-side revalidate native) → JSON `{success, error_message}` khớp contract drawer; success → dispatch `reload-customer-section-data` → subtotal/totals đồng bộ; error → inline message (chuỗi native sales-rule, đã có trong `Launchpad_MageplazaTranslate` dict — LL-0012(4)).
- **Promo message**: CMS block identifier `cart-drawer-promo` (per store view, Admin tạo) render vào container `cart-drawer.totals.before` qua theme layout; block chưa tồn tại → render rỗng, không lỗi.
- Không đổi: checkout OSC flow, cart page, Mageplaza Quick Cart (giữ disabled), payment/shipping logic.

### Constraints / Rules

- **Không sửa Mageplaza/vendor in-place**: theme override `cart-drawer.phtml` verbatim-copy + minimal diff (pattern BUG-SDZPCD); module `Launchpad_QuickCart` mới (vendor prefix `Launchpad_` theo chỉ thị 09-08), PHP 8.2 + `strict_types`, controller validate → delegate `CouponManagement` → respond (no business logic in controller, [BLOCK] §7.2).
- **Không tin client**: coupon revalidate server-side qua `CouponManagement` (sales rules + BR-P01 cap collector chạy native trong totals); form_key CSRF validate.
- Chuỗi storefront mới → **cả `vi_VN.csv` + `en_US.csv`** (BR-001); ưu tiên reuse key có sẵn trong theme dict từ SLP-128/133 (Apply Discount, Cancel coupon, coupon messages…).
- Tailwind v4: class mới trong override phải nằm trong `@source` scope; rebuild `web/tailwind/` + grep CSS sau build (lesson BUG-MNEZ92).
- CLI/static ops chạy as `secomm` (memory shell-traps).
- Coupon → totals feed OSC checkout: test gate gồm E2E checkout regression sau coupon-from-drawer (tinh thần rule OSC §7.1).

### Out of Scope

- Free-shipping progress bar — **phase 2**, chờ business chốt nguồn threshold (config / Cart Price Rule / TableRate) — DEC-TASKQX93G3-001.
- Payment-specific Buy Now routing; cart upsell engine; custom promotion rules (đúng ticket).
- Mageplaza_QuickCart — giữ disabled.
- Cart page (`/checkout/cart/`) — không đụng (coupon/qty trên cart page giữ nguyên behavior).
- Nội dung CMS block `cart-drawer-promo` — store data, Admin tạo (record chỉ ship identifier + render path).

### Acceptance Criteria

- **AC-001** (live, cả 2 store): qty tăng/giảm/nhập trong drawer → cập nhật không reload page; subtotal trong drawer khớp backend (đối chiếu cart page sau refresh sections).
- **AC-002**: qty = 0 hoặc rỗng bị clamp min=1; nhập qty vượt salable → per-item error message hiển thị (chuỗi native server trả), cart không hỏng.
- **AC-003**: remove item trong drawer → không reload, item biến mất, subtotal cập nhật (native regression — phải không vỡ sau override).
- **AC-004**: apply coupon hợp lệ trong drawer → totals/subtotal đồng bộ backend, chip mã hiển thị; cancel coupon → totals trả về; coupon SAI → inline error VI/EN đúng store; trạng thái applied tồn tại sau reload trang (section `coupon_code`).
- **AC-005**: CMS block `cart-drawer-promo` (khi Admin tạo + active) render trong drawer trên cả 2 store; không có block → drawer render bình thường không lỗi.
- **AC-006**: empty/loading/error states rõ ràng không vỡ (native regression sau override): empty drawer, loading overlay khi POST, error per-item.
- **AC-007**: mobile 375px + desktop 1280px usability pass (drawer full-height, stepper chạm được, console sạch), en_US identity sạch cho chuỗi mới.
