## Mini Spec

### Goal

- Modal sign-in (login/register/forgot/social/email tabs) render đúng khối lượng trong dialog, UI theo token theme (card, radius-lg, color-primary, ink), ở cả 1280px và 375px.
- Social buttons (modal + 3 trang auth) đồng bộ một style duy nhất với dashboard đã duyệt ở BUG-QKX5BW (SLP-185): inline SVG brand icon + static Tailwind utilities.
- Không đổi bất kỳ behavior nào: form action/endpoint, `data-mage-init`, `onclick`, popup OAuth `window.open`, luân chuyển tab (`showLogin/createBtn/forgotBtn`), request-info flow — giữ nguyên 1:1.

### Expected Behavior

- Click link "Đăng nhập" trong dropdown tài khoản → dialog hiện ra với form login + cột social buttons, đóng bằng nút ×/click ngoài như hiện có.
- Nút "Đăng nhập với Facebook/Google" (modal + trang) → gọi `window.open(login_url + ?timestamp, label, params)` như cũ (local credentials dummy → popup OAuth trả lỗi là behavior network, không thuộc AC UI).
- Tab create/forgot bên trong modal hoạt động như hiện có (`display` toggle qua class hook giữ nguyên).

### Constraints / Rules

- **Không sửa Mageplaza in-place** — chỉ theme override (`Mageplaza_SocialLogin/templates/...`, extend copy `Mageplaza_SocialLoginPro/templates/hyva/header/modal.phtml`) + CSS trong theme build (`web/tailwind/theme/`).
