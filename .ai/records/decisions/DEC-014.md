# Decision Record: Audit-trail storage

## Context

Requirement: preserve an immutable audit trail for rejected ('97'/'04'/'01') and duplicate ('02') callbacks. Current code only `logger->debug`. Security/compliance category; storage choice may imply schema.

## Decision (open — SA)

Choose one: (a) **new DB table** (`secomm_vnpay_callback_audit`) — immutable, queryable, **schema + migration → SA review**; (b) append-only structured log file; (c) Magento native payment-transaction history (insufficient for rejected/duplicate). Fields: timestamp, `vnp_TxnRef`, `vnp_TransactionNo`, RspCode, reason, raw-payload hash.

## Alternatives

- `logger->debug` only (not durable/queryable — rejected for compliance).
- Reuse sales tables (pollutes order data — rejected).

## Consequences

(a) adds a migration (SA gate); (b) needs log retention/rotation policy. Decision bounds the implementation scope.

## Affected components

New audit model/table OR logger config; `Ipn.php` (record on every terminal branch).
