# Decision Record: Generic VN address capability placement — extend Secomm_VietNamAddress

> **Refined by [DEC-018](DEC-018.md):** scope này chỉ bao gồm phần **generic** (data + cart estimate cascade). Phần **per-shipping-method customization** → Launchpad (project), KHÔNG thuộc module.

## Context

[FEAT-005](../features/FEAT-005.md) require VN-market shipping address support (full hierarchy Province → City → Ward cho cart estimate + customize từng shipping-method cho VN). Câu hỏi architecture: **code VN-specific này đặt ở module nào?**

Thực trạng module:
- `Secomm_VietNamAddress` — **data-only** (chỉ `InstallVietNamAddressPatch` seed data VN).
- `Secomm_AddressDropdown` — generic, sở hữu city/sub_city **data + GraphQL `GetListCity`/`GetListSubCity` + dropdown UI** (FEAT-001, dual-theme).
- DEC-8 (boundary): module generic (`AddressDropdown`) **không** chứa market-specific; VN-specific phải tách riêng.

Tier-2 (shipping + address data — §12) → Level-2 architecture decision, SA/TL.

## Decision

**Phần GENERIC của VN address capability (full hierarchy — reuse data/GraphQL + cart estimate cascade) nằm trong `Secomm_VietNamAddress`** — mở rộng module data-only hiện tại thêm lớp `view/frontend` (cart estimate override conditional country=VN).

- `VietNamAddress` **phụ thuộc** `Secomm_AddressDropdown` (module.xml sequence) để **reuse** city/sub_city data + GraphQL + Alpine dropdown pattern (`hyva/address/edit.phtml`).
- `Secomm_AddressDropdown` (generic) **không thay đổi** — không pollute bằng logic VN (DEC-8).
- Logic VN **gate theo country=VN** (non-VN unaffected).
- **KHÔNG bao gồm per-shipping-method customization** — phần đó ở Launchpad (project), xem [DEC-018](DEC-018.md).

Approved via user acting as SA/TL authority (chat 2026-07-29, module-placement question — chọn "Mở rộng Secomm_VietNamAddress"). Formal SA/TL name [TBD].

## Alternatives

- **New module `Secomm_VietNamShipping`** (separate VN checkout/shipping module, depends on AddressDropdown + VietNamAddress): rejected (user) — prefer gộp market-specific VN vào một chỗ (`VietNamAddress`) thay vì thêm module.
- **Code trong `Secomm_AddressDropdown`, gate country=VN**: rejected — vi phạm DEC-8 (generic module chứa market-specific logic).

## Consequences

- (+) Market-specific VN cô lập trong `VietNamAddress`; `AddressDropdown` giữ reusable/generic (DEC-8).
- (−) `VietNamAddress` từ data-only → data + frontend/shipping (phình trách nhiệm module); thêm dependency `VietNamAddress → AddressDropdown`.
- (−) Cần verify không break seed-data responsibility khi thêm frontend layer.
- **Open (consider, out of scope):** dài hạn có thể move city/sub_city **data + GraphQL** từ `AddressDropdown` sang `VietNamAddress` để `VietNamAddress` tự chứa (không phụ thuộc ngược). Flag cho SA.

## Affected components

`Secomm_VietNamAddress` (mở rộng `view/frontend` + shipping customization); `Secomm_AddressDropdown` (reuse, unchanged); `app/design/frontend/Secomm/launchpad` (cart estimate surface override); `Mageplaza_TableRateShipping` (VN customize).
