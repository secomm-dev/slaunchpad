# Ticket Readiness Checklist

- [ ] Ticket theo standard template format
- [ ] Acceptance criteria testable và specific
- [ ] Priority đã assign (P0/P1/P2/P3 hoặc Critical/High/Medium/Low)
- [ ] Dependencies đã identify (hoặc explicit "none")
- [ ] Workflow mode đã assign (A/B/C/D)
- [ ] Estimate đã provide (range OK)
- [ ] Design/mockup đính kèm (nếu UI change)
- [ ] Implementation plan đã draft (Mode A/B) hoặc approach note (Mode C)
- [ ] Relevant project-context sections đã review
- [ ] High-risk areas đã check — escalation nếu cần
