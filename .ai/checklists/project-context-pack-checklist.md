# Project Context Pack Checklist

## Completeness

- [ ] 01_PROJECT_OVERVIEW.md — project basics, client, timeline đã fill
- [ ] 02_BUSINESS_RULES.md — tất cả business rules đã document theo domain
- [ ] 03_ARCHITECTURE_AND_INTEGRATIONS.md — architecture + integration list đã fill
- [ ] 04_CUSTOM_MODULES_AND_CODE_AREAS.md — modules đã list với risk levels
- [ ] 05_API_CONTRACTS.md — API endpoints đã document theo integration
- [ ] 06_KNOWN_CONSTRAINTS_AND_RISKS.md — bugs, risks, legacy code đã document
- [ ] 07_GLOSSARY.md — domain terms và abbreviations đã document
- [ ] 08_SPEC_TEMPLATE.md — có (copy của feature spec template)

## Accuracy

- [ ] Business rules trace được về client input (không bị invent)
- [ ] Version numbers match actual project state
- [ ] Integration list match actual integrations
- [ ] Module list match source code scan

## Currency

- [ ] Không có thông tin outdated từ các release trước
- [ ] Resolved issues được mark là resolved (không còn list là open)
- [ ] Risks mới phát sinh từ release trước đã được thêm
