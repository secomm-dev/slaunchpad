# Onboarding Checklist

## Setup

- [ ] Repository đã clone local
- [ ] Local development environment đang chạy
- [ ] Claude Code đã install và authenticated
- [ ] Có access vào project management system (Jira/Linear)
- [ ] Có access vào communication channels (Slack)
- [ ] Có access vào project documentation và wikis

## Context

- [ ] Đã đọc tất cả project-context/ files
- [ ] Đã đọc AGENTS.md — hiểu workflow mode, restrictions, escalation rules
- [ ] Walk-through với TL về high-risk areas và escalation process
- [ ] Hiểu business domain từ 02_BUSINESS_RULES.md
- [ ] Hiểu architecture từ 03_ARCHITECTURE_AND_INTEGRATIONS.md

## Skills

- [ ] Đã demonstrate: analyze một ticket với AI toolkit
- [ ] Đã demonstrate: generate và follow một implementation plan
- [ ] Đã demonstrate: chạy AI pre-review trước TL review
- [ ] Đã demonstrate: submit một PR với PR template
- [ ] Đã demonstrate: update project-context/ sau một task

## First Tasks

- [ ] First Mode C ticket đã assign (bug fix hoặc config change)
- [ ] 3 PR đầu được TL review kỹ
- [ ] First Mode B ticket assign sau 5 Mode C tickets thành công
- [ ] Context contribution sau first release
