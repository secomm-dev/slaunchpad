# before-client-handoff


- **Mục đích**: Outward-facing milestone — confidentiality + docs + signoff.
- **Khi trigger**: UAT / go-live / closeout, trước khi gửi client.
- **Checklist**: [`../../checklists/client-handoff-checklist.md`](../../checklists/client-handoff-checklist.md)
