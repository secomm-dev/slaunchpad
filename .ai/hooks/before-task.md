# before-task


- **Mục đích**: Confirm context load, scope rõ, plan tồn tại trước khi code.
- **Khi trigger**: Developer start một task (trước khi viết code).
- **Checklist**: [`../../checklists/pre-task-checklist.md`](../../checklists/pre-task-checklist.md)
- **Engineering Standards**: load `ENGINEERING_PRINCIPLES` + capability-relevant standards (`.ai/project-context/engineering-standards/`) trước khi code.
- **Research Engine: run research trigger (mandatory unless bypass: typo/UI/config/formatting). Xem `.ai/research/RESEARCH_ENGINE.md`.
- **Workflow Engine**: select workflow (role + project-type); identify current state; validate function allowed. (mandatory unless bypass: typo/UI/config/formatting). Xem `.ai/research/RESEARCH_ENGINE.md`.
- **Evidence yêu cầu**: Plan/approach note tồn tại; context đã đọc (note trong task).
- **Xử lý khi fail**: Không start code — resolve blocker (missing AC/plan) hoặc escalate Tier 1.
