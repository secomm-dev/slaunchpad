## Description

Thêm field **Maximum Discount Amount** vào Marketing → Promotions → Cart Price Rules → **Actions**, theo DEC-FEATJKZM68-001 §7:

1. **Plugin sau `Magento\SalesRule\Model\Rule\Metadata\ValueProvider::getMetadataValues()`** (`etc/adminhtml/di.xml`) — inject field `maximum_discount_amount` vào `actions.children` meta: `formElement: input`, `dataType: text`, validation `validate-number` + `validate-zero-or-greater`, label **"Maximum Discount Amount"**, note: *"Limits the total product discount generated by this rule. Leave empty or set to 0 for no limit."* — **KHÔNG override `sales_rule_form.xml`** (tránh copy 700 dòng core brittle theo upgrade).

2. **JS component `max-discount-field.js`** — extend UI input component, imports value `simple_action` từ cùng fieldset → **visible (và enabled) chỉ khi `simple_action == 'by_percent'`**, ẩn + disabled khi action khác (mirror pattern `Magento_SalesRule/js/form/element/apply_to_shipping`). Disabled field không submit giá trị stale.

3. **i18n `vi_VN.csv` + `en_US.csv`** cho label + note (BR-001 bilingual).

4. Data path đã có sẵn từ TASK-33J3RP (DataProvider full-data + loadPost + column) — không PHP glue.

**Runtime guard độc lập UI:** TASK-5H8WKE check `simple_action` lúc calc — đổi action sang unsupported type KHÔNG ảnh hưởng calculation dù DB còn giá trị (spec AC-008).
