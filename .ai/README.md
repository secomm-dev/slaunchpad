# `.ai/` — Project AI Toolkit (Secomm Launchpad)

> Hệ thống AI toolkit cho project **Secomm Launchpad** (Magento 2.4.8-p5 + Hyvä 3.x). Generated by Secomm Production AI Toolkit (v4) on 2026-07-14.

## Điểm bắt đầu (entry points)

| Khi nào | Đọc gì |
|---|---|
| Bất kỳ task nào | **`AGENTS.md`** — single source of truth (§4 cho biết đọc `project-context/` files nào theo task class) |
| Resume work | `project-context/memory/CURRENT_STATE.md` + `NEXT_TASK.md` |
| Muốn biết next step / quyết định mở | `runtime/PROJECT_NAVIGATOR.md` + `runtime/DECISION_QUEUE.md` |
| Lần đầu vào project | `WELCOME.md` + `guides/QUICK_START.md` + `guides/CHEATSHEET.md` |

## Cấu trúc thư mục

```
.ai/
├── AGENTS.md                  # SSOT — tất cả rules (§1–14 + §8.5/§8.6)
├── WELCOME.md                 # file đầu tiên user đọc (enablement)
├── project-context/           # context ổn định (update sau release)
│   ├── 01..08                 # base (overview, business rules, architecture, modules, API, risks, glossary, spec)
│   ├── 09..12                 # magento-hyva overlay (module map, checkout/payment, cron/cache, upgrade)
│   ├── CODING_RULES.md        # shared + magento + hyva/Tailwind v4 + project overrides
│   ├── engineering-standards/ # standards library (base + Magento + Hyvä + PHP + tech)
│   └── memory/                # working memory (CURRENT_STATE, NEXT_TASK, DECISIONS, ...)
├── instincts/                 # auto-apply decision rules
├── rules/                     # 11 first-class rules (binding)
├── hooks/                     # 12 lifecycle hooks (checklist-based)
├── mcp/                       # MCP policy (read-only default)
├── commands/                  # legacy command shims (/plan, /spec, /review, ...)
├── evidence/                  # evidence policy ("done requires evidence")
├── agents/                    # 11 agent definitions (BA/SA/TL/Dev/QC/DevOps/Auditor + reviewers)
├── functions/                 # function recipes (orchestrate skills/agents/rules)
├── audits/                    # audit framework (base + magento + hyva)
├── checklists/                # pre/post-task, pre-commit, release, handoff, ...
├── templates/                 # spec/ticket/bug-report/estimation templates
├── research/                  # Research Engine (profile magento+hyva)
├── workflow/                  # Delivery Workflow Engine (state machine)
├── intents/                   # Intent Engine (NL → workflow → functions)
├── initialization/            # Project Initialization records
├── runtime/                   # Human Navigator (project-state.yaml + renders)
├── guides/ reference/ learning/  # enablement kit (Vietnamese, user-facing)
└── toolkit/                   # PROJECT_AI_BLUEPRINT.md + generation-log + selection-manifest + validation-report + toolkit-version
```

## Quy tắc ngôn ngữ

- **AI-facing SSOT** (`AGENTS.md`, `project-context/01–12`, `CODING_RULES.md`, skill files, mcp, commands, reference/) = **English**.
- **Guidance/runtime** (agents, rules, hooks, instincts, evidence, memory, navigator, guides, learning, checklists, templates) = **Vietnamese**.
- Skill **output prose** = Vietnamese (theo `output_language: vi`); code/identifiers/paths/technical terms luôn English.

## Sync / update

- Update toolkit qua function `update-project-ai-tool` (governed bởi `.ai/rules/ai-tool-self-update.md`).
- Mỗi change log vào `CHANGELOG_AI_TOOL.md`.
- Toolkit version + provenance: `toolkit/toolkit-version.md` + `toolkit/generation-log.md`.

> References tới `../../core/`, `../../execution-policy/`, `../../generator-rules/` trong các file copied là **provenance pointers** cho team Secomm (nơi source sống). Trong project standalone, nội dung tương đương nằm trong `AGENTS.md` (§7, §8.x, §10–12) — không cần resolve toolkit path khi delivery.
